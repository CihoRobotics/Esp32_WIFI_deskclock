# Esp32_WIFI_deskclock
The esp32 WIFI desk clock Code for Arduino IDE

I used the esp32 c3 supermini for this project. I used an OLED screen 1.3 inch screen. This project uses WIFI so I did not used an battery because this is a desk clock and not a portable clock but when you want to make it portable you can use battery for making it portable but don'T fooget to have an protection and charge board too:)
